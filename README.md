# SaaS 订阅清点台

本地整理订阅金额、负责人、用途和人工录入的续订通知期限。按币种分别年化，不默认汇率或税率。

## 字段
`asOf` 为复核日期 YYYY-MM-DD；`subscriptions` 数组，每项唯一 `id`、`name`、三字母 `currency`、数值 `amount`、`cadence`（monthly/quarterly/yearly）、`status`（active/cancelled）、`nextRenewal` 日期、`noticeDays`（0—365整数）、`owner`、`purpose`。
金额为每个周期整项费用，而非人均单价。已取消项不计入汇总，但不证明实际取消成功。

## 算术
月/季/年分别乘12/4/1得到年化额，月等值=年化额/12。通知截止日=下次续订日期减通知天数。按UTC日计算，不推断营业日或合同特殊条款。金额使用JavaScript浮点，仅作整理，需对账，不作会计记账。

## 限制
不是账单预测、税务法律财务意见；不连接银行、平台，不实际取消订阅、不自动提醒。相同名称仅提示复核，不证明重复收费。原商机材料的加州SB122税务说法未核实，本工具不采纳该说法或任何默认税务规则。币种只做代码格式检查，不保证币种实际存在。

## 使用与隐私
下载所有文件置于同一目录，双击index.html，载入虚构示例，修改JSON再生成；也可导入UTF-8 JSON（限1MB）。没有API key，没有安装步骤，没有外部请求、遥测或本地持久化。清单与分析报告是不同文件：清单可恢复编辑，报告不可恢复编辑。下载前自行检查内容授权。输入只在内存中，未保存时刷新会丢失。

可直接用中文表单填写、增删条目；高级JSON编辑仍保留。每个数组表单显示前50项，超出项保留但需高级编辑。表单不代表数据已验证，生成报告时再检查。不要输入未授权个人信息、凭据或敏感财务账号。没有第三方代码和素材，MIT授权。示例原创虚构。

## 测试
安装Node.js后执行 `node --test test.js ui.test.js form.test.js roundtrip.test.js`。自动测试不等于真实浏览器验收。真实浏览器导入、下载和移动视觉尚未验证，实验性v0.1，不承诺生产可用。

## 候选取消情景
每项 `decision` 可选 retain/review/cancel_candidate（默认review），由你人工标记。报告单独列出候选取消项的年化金额，不修改当前总额；它不是立即可省金额，不考虑退款、违约金或剩余期限，必须核查合同。该功能不执行取消。

## 保存与恢复编辑
1. 用表单编辑清单，可随时点击“保存清单 JSON（可恢复编辑）”。下载文件名为 `subscription-list.json`，请确认浏览器实际完成下载。
2. 再次打开页面后，用“导入清单 JSON，恢复编辑”选择该文件；全部原始字段（包括负责人、用途、金额、周期、通知期、人工复核意向）恢复，可继续改。
3. 可以保存尚未填写完整的草稿；保存不表示校验或账单核验通过，生成报告时仍会检查。
4. “下载分析报告”产生 `subscription-report.json`，用于查看和复核，不是编辑备份。误选报告导入会明确提示，当前数据保留。
5. 无效或超限导入不会清除当前清单。读取文件期间新增手动修改优先，不会被迟到的文件覆盖。上限1 MB，以保存文件UTF-8字节计算。

当前40项自动测试通过；新增保存→新页面→重新导入→继续表单编辑的闭环为DOM模拟测试，仍不等同真实浏览器下载验收。
